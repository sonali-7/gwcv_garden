Drop your own crop drawings here and the garden map uses them instead of the built-in sprites.

- Name the file after the crop: `carrots.png`, `sweet-potato.png`, `garlic.png`.
  Or after a sprite group to cover several crops at once: `leafy.png` (lettuce, kale, spinach), `pod.png` (beans, peas).
- Square, transparent background. 16×16 or 32×32 pixels looks crispest; any size works.
- Refresh the page after adding a file.
